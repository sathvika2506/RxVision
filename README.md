# RxVision 


RxVision is an Android application that helps users analyze potential interactions between medicines using camera input and manual entry.

## Features

*  Capture medicine using camera
*  Manual medicine input
*  Interaction analysis (Safe / Moderate / Danger)
*  Modern UI with Jetpack Compose

## Tech Stack

* Kotlin
* Jetpack Compose
* Android Camera API

## How to Use

1. Download APK from repository
2. Install on Android device
3. Allow camera permission
4. Scan or enter medicines

## Future Scope

* OCR-based medicine detection
* FDA API integration
* ML-powered interaction analysis
